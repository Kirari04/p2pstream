2. **Indirect H2 write/copy/credit feedback: real mechanism, unresolved magnitude.** `public_routing.go:729` supplies the fixed32KiB pool. Go1.26.6 `httputil/reverseproxy.go:696–754` performs serial Read then Write. Yamux `stream.go:123–177,440–493` frees receive storage and considers a synchronous normal update at `max/4`. H2's additional sub-millisecond writes can alter consumption/ACK cadence, including earlier conditioning. These measurements cannot infer its nonlinear effect on TCP history.
3. **Seconds-long public H2 flow-control/write blocking as the immediate stall: contradicted for these selected copies.** H2 seq11/14 spend8.76/8.81s inside Read; no individual Write reaches1ms. H2 seq9/15 pass with substantial write cost too. Thus sustained writer flow-control waits during these writes would be inside the measured Write interval. Small buffering/final flush and indirect upstream feedback prevent the broader claim that H2 is irrelevant.
