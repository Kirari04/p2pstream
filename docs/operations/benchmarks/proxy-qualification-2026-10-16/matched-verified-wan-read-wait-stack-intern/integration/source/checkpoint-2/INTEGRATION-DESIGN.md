# Lossless stack-intern integration derivative

This diagnostic-only derivative keeps the capacity observer binary, agent,
generated timed runner, fixed capture sequences, transfer schedule, TLS checks,
resource scope, and lifecycle gates unchanged.  It changes only the offline
post-endpoint trace path: the reviewed adapter streams pinned Go parsed output
through the lossless stack interner, then the intern-aware analyzer reads the
canonical file and ledger.

Every selected sequence records and gates the adapter, pinned parser,
canonicalizer, and analyzer statuses separately.  The adapter process record
must prove both owned child groups joined naturally without TERM/KILL, stderr
overflow, deadline, interruption, or input/source mutation.  The arm validator
binds exact per-sequence raw trace, canonical file, ledger, status, process
record, reduction, server, runner, protocol, certificate, sequence, and origin
identity.  The 512 MiB bound applies to the physical canonical file and the new
4 GiB bound applies to logical expanded parsed text; neither changes the 64 MiB
raw trace cap or any public runtime setting.
