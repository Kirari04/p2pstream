# Native HTTP/1 stage source checkpoint v5

Source-only checkpoint; nothing here has been formatted, compiled, tested, built, or run. The outer wrapper remains excluded until a reviewed portable bundle supplies exact manifest, source-tree, patch, binary, BuildID, and checksum-index identities.

The endpoint uses the production server path `AgentTransports.getOrCreate` -> `newAgentPooledHTTPTransport` -> `dialViaAgentWithCapacity` and the production agent path `serveTunnelSessionWithPolicyCapacityAndResources` -> `handleTunnelStream` -> destination socket/relay. Physical setup, origin, ledgers, reporting, and admin endpoints are tagged fixture code.

Every report records a source-derived exact configuration with two sections: the accepted TLS/Yamux configuration and the HTTP-stage settings actually configured by this fixture. The latter pins fixed capacity 16, native 30-second idle timeout, 90-second response-header timeout, max idle/global-per-host 11 (the actual pooled partition of total fixed capacity 16), max-conns-per-host 0, enabled keep-alives, 32 KiB response pump, 8 KiB final consumer, 35,840-byte origin writes without Flush, native upload `io.Copy` into SHA-256, and conditioning close-all behavior. The future build manifest must contain exact server/agent objects; the runner recursively validates their types and exact equality to both role reports.

The runner executes one 16-phase cohort at configured 80 ms RTT/1 Gbit in fresh owned server/router/agent namespaces on fixed CPUs server0-3, agent4-7, load8-15. It uses the accepted helper-process lifetime/topology evidence and validates it offline. Admin snapshots use a one-second, one-MiB request bound inside an absolute 35-second wait; transfers retain a separate long request timeout. It queries endpoint state only at readiness, after each completed conditioning phase, at retained post16, and after natural terminal exit. It never polls during payload transfer.

Phases0..7 close the whole HTTP pool and require server pool entries+draining, capacity states, and lane streams to be zero. Each boundary also requires agent capacity, origin requests, and lane streams zero. Registered physical sessions and grown receive limits remain allowed. Phases8..15 use native 30-second pooling/eviction without forced A-D persistence. Post16 is captured before shutdown. Shutdown closes the pool, waits logical quiescence, closes physical sessions, joins handlers, and requires terminal capacity/transport/origin/lane-stream ownership and both ledgers to reach zero.

Downloads keep exact Content-Length and 35,840-byte origin writes without Flush. A bounded 32 KiB pump feeds an 8 KiB final consumer, blocks fast paths, and joins cancellation before releasing its owner. Origin writing reports the independently pinned digest only after exact deterministic writes; the receiver hashes wire bytes. Uploads deliberately retain native origin `io.Copy(sha256.New(), r.Body)`, exact Content-Length, and raw32-byte digest. This differs from the bare fixture's 8 KiB upload sink, so the screen is not single-factor causal evidence.

The 64 MiB working ledger is a conservative fixture allowance/promise, not a hard TLS, heap, RSS, kernel-memory, or resident-byte bound. The 2 GiB aggregate receive-pool ledger records actual reservations/releases, and both roles must show positive growth before any classification.

After every correctness, provenance, configuration, five-socket, topology, lifecycle, ownership, and ledger gate passes, the signature is: conditioning download median phases0..3 >=29.7 MB/s; at least one phase8/10/13 <29.7; phase14 >=29.7. All four post-conditioning downloads >=29.7 is healthy nonreproduction. A below-floor conditioning median is `inconclusive_conditioning`; any other post-conditioning slowdown shape is `inconclusive_other_slowdown`. A reproduced signature requires later fixed contemporaneous bare/HTTP order confirmation. Healthy nonreproduction advances to a separate public-H2 stage. Accepted bare64 is context only.

Omitted layers: public TLS/H2, ReverseProxy and Director/ErrorHandler, and public retry/cache/WAF/shaping paths.
