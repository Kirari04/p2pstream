# Matched verified WAN TCP-state diagnostic evidence

The sustained launcher source and its direct-zero preflight are frozen and
selected. The sustained process closed with native status 1 and no retry. Its
271-file ledger, reviewed safe subset and complete omission partition are
selected. Integrity and natural endpoint closure passed. H1 is
observational-complete and passed its fixed download floors and reuse checks;
H2 is inconclusive because origin reuse expired on sequences 15 and 16 and its
retained-warmup and steady download phases failed the independent floor.

This package preserves the qualification-only TCP-state observer
history. It extends the published byte-credit diagnostic package by hash and
does not revise any earlier performance result or frozen package.

The new observer records sampled Linux TCP provider state around selected local
byte-credit wait boundaries and below-TLS raw-write calls. Samples use
owner-relative monotonic coordinates and join to the existing byte-credit,
raw-write, session, lane, stream and physical-tuple identities. No
cross-endpoint clock subtraction is valid. Provider capture duration encloses
the `RawControl`/query operation; it excludes cursor lookup, owner locking,
record copying and JSON serialization and cannot be subtracted from transfer
time as total observer overhead.

The two internal 4096-record caps are memory-safety ceilings. The authenticated
control response remains bounded at 4 MiB. An oversized response invalidates
the interval/run and preserves bounded size/hash/error metadata; evidence is
never truncated and labeled healthy.

  bytes equal the clean checkpoint-5 payload; checkpoint 6 changes only a stale
  test expectation. The withdrawn checkpoint-4 in-place mutation and its
  erratum remain preserved.
- The strict TCP validator passed 25 focused cases with natural ownership
  closure. Controls cover empty boundary snapshots, cursor progress, two-stream
  sample ordering, exact selected wait joins, mid-interval congestion-control
  mismatch, unfinished cursor samples, oversized payloads and sticky invalid
  states.
- Audited build attempt 1 is a preserved failed fixture assertion. Attempt 2
  passed and produced the accepted agent/server tuple. The binaries are not
  published; their SHA-256 hashes and the complete selected build records are.
- Runner sources 1 and 2 preserve contract failures. Runner source 3 passed its
  fresh materialization, receipt publication and final contract. The workload
  runner and timed transfer function remain byte-identical to the mature
  byte-credit diagnostic.
- The tiny run completed 16 H1 and 16 H2 transfers and accepted both arms. It
  validated TCP state on all five owners, selected stream joins, protocol and
  certificate identity, and exact natural process closure. The maximum observed
  authenticated response was 198,534 bytes against the unchanged 4 MiB bound.
  This 4 MiB-payload smoke is schema/lifecycle evidence, not performance
  evidence.
- The sustained run completed 16 H1 and 16 H2 rows with exact integrity and
  natural closure. H1 retained-warmup and steady download minima were
  29.810187 MB/s and 29.856107 MB/s and passed the 29.7 MB/s floor. H2
  retained-warmup and steady minima were 27.633615 MB/s and 16.810103 MB/s and
  failed it. H2 sequence 14 retained same-origin reuse after 28.478 seconds and
  measured 16.810103 MB/s; sequences 15 and 16 revisited after 35.149 and
  35.487 seconds with new origin connections, so the H2 cohort is
  `inconclusive-upstream-reuse`. H1 sequence 9 recorded nine retransmissions
  totaling 13,032 bytes and H2 sequence 14 recorded eight totaling 11,584 bytes;
  both had zero RTO-count delta. These sampled facts do not establish cause.
- The pre-transfer slow-start thresholds already differed: 466/462/460 for H1
  sequences 9/11/14 and 240/246/246 for H2. H2 sequences 9
  and 11 failed the floor with zero cumulative retransmission delta, while H1
  sequence 9 passed despite its retransmission delta. This discrepancy weighs
  against retransmission as a sole explanation, but the discrete samples do not
  prove that the threshold difference caused the throughput result.
- A read-only Linux CUBIC and Yamux source review finds that the finite
  thresholds predate the selected timed DATA intervals. Idle restart and the
  ordinary application-limited validation path cannot lower an initially
  infinite threshold; HyStart, earlier recovery/loss, and other explicit kernel
  setters remain possible creators. The proposed transition discriminator is
  future source work only. Namespace counters are not per socket, so the review
  does not authorize another run, policy change, runtime fix, or causal claim.
  Its append-only erratum requires bracketing every existing raw write from
  owner bind rather than DATA writes alone and excludes namespace counters from
  per-owner attribution.

## Interpretation limits

Offline source checks, focused tests, an audited build and synthetic contracts
do not establish a WAN cause, a runtime fix, throughput clearance, modern-path
parity, or release readiness. TCP observations are discrete and cursor reads
around provider capture are intentionally non-atomic. Progress between the
existing byte-credit record and TCP sample is preserved as a confounder rather
than forced into false equality. A clean local sample does not rule out public
write/inter-read feedback amplification.

## Package design

The reviewed selection contains 1,372 files / 55,895,783 bytes: 1,179 files /
47,074,155 bytes for the deterministic ancillary archive and 193 files /
8,821,628 bytes loose. Each 271-file WAN run is partitioned into 135 selected
and 136 hash-bound omissions. Source/checkpoint history belongs in the archive;
selected WAN status, attestation, summary and review records remain loose.

The package selects immutable source checkpoints, diffs, contracts, execution
records, lifecycle/status files and compact materialization/publication
receipts. It omits reconstructed repositories, active materialized duplicates,
Go caches, compiled binaries/archives, private keys, bearer/authentication
values, readiness/config/environment state, endpoint logs and temporary
runtime state. Immutable ledgers and explicit omission tables bind excluded
bytes. The deterministic archive preserves repeated source, contract, exact
source-excerpt and raw selected records; compact status, summary, attestation,
review and public-certificate records remain loose.

The nonprinting exact-value scan accepted all 1,372 selected artifacts. It
compared six recoverable labels (two private-key values and four
authentication-like JSON values), found zero matching artifacts and printed no
values. Process-local values that were never persisted remain outside the scan.
